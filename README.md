# Snowflake-GCC-Cli-Hacakthon
Snowflake-native Supply Chain Intelligence platform: governed ontology, canonical KPIs (OTD, Fill Rate, DOI, Freight/Unit), Cortex Agent with 8 tools (Analyst, Search, custom LLM/ML), Streamlit admin console, DMFs, masking + row-access policies, ML forecasting. Built end-to-end with the Cortex Code (CoCo) CLI.
